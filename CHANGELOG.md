# 0.2.0rc2

The installed wheel now includes two offline GitHub delivery examples, accessible with --demo clean and --demo drift. A new first-use guide shows how to compact saved sender and receiver records into JSON Lines, interpret exit codes and investigate discrepancies. Packaging includes license metadata and a source distribution with the test suite. Existing input schemas and JSON reports remain compatible with rc1.

# 0.2.0rc1

Added GitHub sender and receiver adapters, precise JSON number handling, a basic text report and a local wheel to the original digest-manifest prototype.
